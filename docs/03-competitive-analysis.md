# 03 — Competitive Analysis

## Методология сравнения

Конкуренты оценены по 8 осям, важным для ЦА (Scrum Master команд 30+):

1. **Scrumban-поддержка из коробки** — насколько методология поддерживается без плагинов и кастомизации.
2. **WIP-лимиты** — есть ли, настраиваемые ли, есть ли визуальные алерты.
3. **CFD** — есть ли Cumulative Flow Diagram, насколько полезный.
4. **Cycle/Lead time scatter** — есть ли scatter plots с percentile-анализом.
5. **Вероятностный прогноз** — Monte Carlo или аналоги.
6. **WIP-рекомендации** — обоснование математикой (Little's Law и т.п.).
7. **РФ-интеграции** — 1С, Yandex, GitFlic/GitVerse, Pachca/VK Teams.
8. **Модель развёртывания** — SaaS / on-prem / hybrid.

## Зарубежные конкуренты

### Jira (Atlassian)
- **Scrumban из коробки:** частично, нужны гибриды Scrum+Kanban templates.
- **WIP:** ★★★★☆, настраиваемый, но строгих soft/hard нет.
- **CFD:** ★★★★☆, хороший, в Cloud-версии.
- **Scatter:** ★★★☆☆, отдельный отчёт Control Chart.
- **Monte Carlo:** ★☆☆☆☆, только через платные плагины (eazyBI, Scrum Mastered).
- **WIP-рекомендации:** ★☆☆☆☆, нет.
- **РФ-интеграции:** ★☆☆☆☆, после ухода Atlassian — нулевые.
- **Deploy:** Cloud (ушёл из РФ), Data Center (on-prem, дорого).
- **Итог:** лидер по ширине, **недоступен из РФ, нет ядра нашего дифференциатора**.

### ClickUp
- **Scrumban из коробки:** ★★★☆☆, 15+ views, надо собирать.
- **WIP:** ★★★☆☆, ограниченная поддержка.
- **CFD:** ★★☆☆☆, упрощённый.
- **Scatter:** ★★☆☆☆, только базовый.
- **Monte Carlo:** ★☆☆☆☆, нет.
- **WIP-рекомендации:** ★☆☆☆☆, нет.
- **РФ-интеграции:** ★☆☆☆☆.
- **Deploy:** только Cloud.
- **Итог:** много фич, **перегружен, слабая аналитика, нет on-prem**.

### Monday.com
- **Scrumban:** ★★☆☆☆, шаблоны есть, но не родные.
- **WIP:** ★★☆☆☆, ограниченная.
- **CFD:** ★☆☆☆☆, нет из коробки.
- **Deploy:** только Cloud.
- **Итог:** красивый UX, **слабая агile-аналитика, не наш профиль**.

### Asana / Linear / Trello
- **Scrumban:** от ★☆☆ до ★★★; Linear ориентирован на engineering, но без Scrumban-specific фич; Trello — простые доски.
- **Итог:** целятся в другие сегменты (Trello — малые команды, Linear — software engineering teams без Agile-аналитики).

## Отечественные конкуренты

### Kaiten
- **Scrumban из коробки:** ★★★★★, явно позиционируется для Scrum+Kanban.
- **WIP:** ★★★★★, полноценный.
- **CFD:** ★★★★☆, есть.
- **Scatter:** ★★★☆☆, базовый.
- **Monte Carlo:** ★☆☆☆☆, нет.
- **WIP-рекомендации:** ★☆☆☆☆, нет (только визуализация текущего состояния).
- **РФ-интеграции:** ★★★☆☆, базовые.
- **Deploy:** SaaS + on-prem.
- **Итог:** **прямой конкурент**, наиболее близкий по ядру. Наш дифференциатор — **вероятностные прогнозы и обоснованные рекомендации**, которых у Kaiten нет.

### Yandex Tracker
- **Scrumban:** ★★★☆☆, поддерживает, но enterprise-ориентирован.
- **WIP:** ★★★☆☆, ограниченный.
- **CFD:** ★★★☆☆, есть в отчётах.
- **Scatter:** ★★☆☆☆.
- **Monte Carlo:** ★☆☆☆☆, нет.
- **WIP-рекомендации:** ★☆☆☆☆, нет.
- **РФ-интеграции:** ★★★★★, нативные с Yandex-экосистемой.
- **Deploy:** SaaS на Yandex Cloud.
- **Итог:** для крупного enterprise, **сложный, дорогой, избыточный для команд 30+**.

### Weeek
- **Scrumban:** ★★★☆☆, есть поддержка.
- **WIP:** ★★☆☆☆.
- **CFD / Scatter / Monte Carlo:** ★☆☆☆☆, минимально.
- **РФ-интеграции:** ★★★★☆.
- **Deploy:** Cloud.
- **Итог:** «всё-в-одном» (CRM, knowledge base, task tracker), **distributed фокус, слабая Agile-аналитика**.

### YouGile
- **Scrumban:** ★★☆☆☆, простые канбан-доски.
- **WIP:** ★★☆☆☆.
- **CFD:** ★☆☆☆☆, практически нет.
- **РФ-интеграции:** ★★★☆☆.
- **Deploy:** Cloud + on-prem.
- **Итог:** для малых команд до 10 человек, **не наш сегмент**.

### Pyrus
- **Scrumban:** ★★☆☆☆.
- **Deploy:** Cloud + on-prem.
- **Итог:** фокус на BPM и документообороте, **не Agile-инструмент**.

## Рыночная карта (2×2)

Оси: **широта функционала** × **глубина Agile-аналитики**.

- **Широкий + глубокий:** Jira (недоступен РФ), ClickUp (перегружен, слабая аналитика).
- **Узкий + глубокий:** *наша ниша* — Scrumban-специализированный инструмент с лидерством в аналитике.
- **Широкий + слабый:** Kaiten, Weeek, YouGile, Pyrus, Yandex Tracker.
- **Узкий + слабый:** Trello, специализированные канбан-приложения.

## Наша ниша, конкретно

**«Lightweight Scrumban-инструмент с вероятностной аналитикой и математически обоснованными рекомендациями, оптимизированный для русскоязычных команд 30+».**

Отличия от основного конкурента (Kaiten):
1. **Monte Carlo прогноз доставки** — у Kaiten нет.
2. **Little's Law рекомендации по WIP** — у Kaiten нет.
3. **Percentile-based stuck-task alerts** — у Kaiten нет.
4. **Фокус на Scrum Master'е**, а не на гибкий «инструмент для всего».
5. **Открытый research** (в дипломе публикуется методология и ограничения ML-подходов).

Отличия от Yandex Tracker:
1. **Ориентация на средний сегмент (30+, не 500+)** — проще, быстрее, дешевле.
2. **Scrumban-first**, не «поддерживает и Scrum, и Kanban, и всё остальное».

## SWOT-анализ нашего продукта

### Strengths
- Уникальное ядро аналитики, не имеющее аналогов в РФ-сегменте.
- Прозрачность расчётов (каждая цифра обоснована формулой).
- Small footprint — быстрее конкурентов в развёртывании, меньше требований к инфраструктуре.
- Открытый research — повышает доверие.

### Weaknesses
- Соло-команда → ограниченный темп развития.
- Новый бренд → нет доверия рынка на старте.
- Отсутствие нативной мобилки в MVP.
- Малый набор интеграций в MVP.

### Opportunities
- Уход Jira и Trello → освободившийся спрос на замену.
- Тренд на импортозамещение → поддержка со стороны государственных и окологосударственных заказчиков.
- Рост интереса к process mining и data-driven Agile в СНГ.

### Threats
- Kaiten может добавить вероятностную аналитику в свой продукт.
- Yandex Tracker может упрощаться и целиться в средний сегмент.
- Возврат Atlassian на российский рынок при геополитическом потеплении.
- Большие игроки (VK Tech, Yandex) могут запустить аналог при наличии спроса.

# Список и массовые действия

## Вид «Список»

Переключатель вида доски → «Список». По умолчанию задачи сгруппированы по колонкам доски; меню «Группировка» собирает их по исполнителю, классу обслуживания или эпику. У каждой группы свой заголовок с WIP-лимитом, своя строка колонок, строка «Добавить задачу» и итоги внизу: сумма SP и затраченного времени.

- **Пустая ячейка – это кнопка.** Блёклые иконки (человек с плюсом, календарь, флажок, «SP») показывают, что значение можно задать прямо здесь.
- **Класс «Стандарт»** показан блёклым флажком, чтобы выделялись только «Срочно», «С дедлайном» и «Нематериальный».
- **Рядом с названием** – подзадачи (клик раскрывает их), описание, чек-лист и блокер.
- Колонки «Спринт», «Чек-лист» и «Время» появляются, когда в них есть данные.

## Выбор задач

- Чекбокс у строки (появляется при наведении).
- Чекбокс в заголовке группы выбирает все её задачи.
- **Shift+клик** выбирает диапазон.
- **Esc** снимает выбор (если открыто меню – сначала закрывает его).

## Массовые действия

Внизу появляется панель:

| Действие | Что делает |
|---|---|
| Статус | переносит в колонку; у колонок видно «мест: N» по WIP-лимиту |
| Класс | меняет класс обслуживания |
| Исполнитель | назначает одного человека вместо текущих или снимает всех |
| Срок | ставит или убирает срок |
| Спринт | добавляет в открытый спринт или убирает из спринта |
| Ещё | в эпик или из эпика, скопировать номера, удалить (только администратор) |

**WIP-лимит.** Если задачи не помещаются в колонку, скрам-мастер увидит «поместится N из M» и решит, перенести всё сверх лимита или только сколько влезет. Срочные задачи лимит обходят, как и при обычном перемещении.

**Честный итог.** Каждая задача проходит те же проверки, что и при обычной правке. Если что-то не прошло, Такт покажет, сколько задач изменилось и почему остальные нет, например «ПОТ-22, ПОТ-36 – Достигнут WIP-лимит колонки (4)». Не прошедшие задачи остаются выбранными – их можно сразу повторить.

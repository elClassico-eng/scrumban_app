# Журнал изменений

Хронология крупных обновлений платформы. Внутри приложения тот же журнал
доступен в боковом меню («Что нового») с указанием, где каждую возможность
попробовать.

## Июль 2026

- **Хаб отчётов и ретроспектив** – отчёты и ретроспективы спринтов доступны из бокового меню, сгруппированы по доскам.
- **Мастер создания спринта** – трёхшаговое создание с выбором задач и вероятностным прогнозом завершения до старта.
- **Симулятор решений (what-if)** – проверка решения до его принятия в спринте: исключение задач, изменение оценок и зависимостей, сдвиг дедлайна.
- **Жизненный цикл спринта** – планирование, старт и закрытие с решениями по незавершённым задачам; перенос дат с обязательной причиной.
- **Неизменяемый отчёт спринта** – итоги, переносы, сравнение прогноза с фактом; выгрузка в CSV и JSON.
- **Ретроспектива с задачами** – пункт ретроспективы превращается в задачу на доске.
- **Дайджест для дейли** – задачи по возрастным корзинам поверх доски.
- **Обновлённая аналитика** – ключевые показатели со спарклайнами, выбор диапазона, единый брендовый стиль графиков.
- **Документация** – ролевая модель с диаграммами и страница внешнего аудита.
